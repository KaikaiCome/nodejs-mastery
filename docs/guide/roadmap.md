# 学习路线与精通标准

本课程面向**已有扎实 JS/TS 与前端工程化基础**的开发者。目标不是“会写接口”，而是：

1. 能解释 Node.js 运行时行为（为什么慢、为什么泄漏、为什么挂）。
2. 能用 Express / Koa（以及 NestJS/Fastify）搭建**企业级**服务。
3. 能独立设计并落地 **BFF 层**：聚合、鉴权、稳定性、可观测。
4. 具备后端架构思维：容量、一致性、可用性、演进。
5. 能定位并解决线上疑难问题。

::: tip 学习方法
每章四步走：**读原理 → 跑示例 → 做实验（[`npm run lab -- <name>`](./labs)，测试自动判分）→ 在主线项目中找到对应代码**。

:::

## 证据等级

你到底掌握到了哪一步？“精通”不能靠自我感觉。本站用五级证据衡量，每一级都比上一级更难伪造：

| 等级 | 证据 | 如何获得 |
| --- | --- | --- |
| L1 已阅读 | 能复述概念 | 阅读章节，标记“已阅读” |
| L2 已练习 | 实验测试全部通过 | [`labs/`](./labs)：9 个实验，自动判分 |
| L3 能在系统中运用 | 主线项目的破坏实验能解释现象，练习带测试 | [全栈主线项目](../mainline/overview) |
| L4 能独立设计 | 独立完成毕业项目，评分 ≥ 80，含 ADR、压测数据、故障演练 | [毕业项目](../project/capstone) |
| L5 经受过生产检验 | 处理过真实事故、承担过线上服务 | 只能在真实工作中获得 |

**本站可以带你稳定达到 L4**——这是“精通 Node.js、具备资深全栈能力”的扎实基础。L5 需要真实流量与真实事故，任何课程都无法替代，[进阶章节](../mainline/senior)给出了在工作中刻意积累的方法。

## 精通标准（自测）

- **入门（L1）**：会用 Express 写 REST 接口，会连数据库。
- **熟练（L2）**：理解中间件机制、统一错误处理、日志、配置、测试；能 Docker 部署；实验全部通过。
- **精通（L3~L4）**：
  - 能画出事件循环各阶段并解释 `setImmediate` vs `setTimeout` 顺序；
  - 能定位内存泄漏（heapdump 对比）与 CPU 热点（火焰图）；
  - 能设计带超时/重试/熔断/缓存的 BFF，并给出 SLO；
  - 能解释 keep-alive 超时导致 502 的根因并修复；
  - 能用事务/条件更新防止超卖，用幂等键 + 唯一约束保证重试安全，并**写出并发测试证明**；
  - 能解释双写问题，用 Outbox + Inbox 实现至少一次投递与消费者去重；
  - 能为一个业务给出分层/领域划分、数据一致性方案、灰度与回滚方案。
- **资深全栈（L4 + 部分 L5）**：在以上基础上，能跨前后端设计端到端的可靠性（如前端幂等键生命周期）、用数据（压测、指标）支撑决策、写 ADR 与复盘、带领他人做技术评审。

完整清单见 [自检清单](../project/checklist)。
